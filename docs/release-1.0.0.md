# Croety 1.0.0

首个 demo release 包含 Create × Goety 的非占位联动内容。

## 内容

- 灵魂马达：128 RPM、8192 SU、临时召唤寿命、跨维度数量限制和护目镜寿命提示。
- 涌动聚晶：ID 为 `croety:waving_focus`，支持 Goety 法杖、锻造仪式和最终 16×16 用户贴图。
- 液态灵魂、液态灵魂桶、Create 储罐/泵/管道/开放管口集成。
- 灵魂能量球：合并、整颗拾取、容量不足保留余量、负值、燃烧和粒子效果。
- 四条 Create 搅拌配方、诅咒之笼和已连接灵魂方舟的注液。

## 验证

- 41 项 GameTest 全部通过。
- `gradlew build` 成功。
- 专用演示服务端成功启动并出现 `Done`。
- 客户端成功加载音频、Flywheel shader 和 Create train hat 配置。
- 用户实机确认马达、聚晶、液态灵魂、管口灵魂球和拾取行为正常。

## 范围说明

原始设计中标记 `#占位` 的萃魂分液池、动力诅咒注入器及依赖它们的萃取/抽取玩法不在 1.0.0。
